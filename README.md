This project focuses on load shedding in a power grid.
The primary goal of load shedding is preventing an entire and udesirable grid collapse 
when the total demand for power exceeds the total supplied by the powerplants.
It is a measure of last resort and functions by disconnecting some areas according to
the priority of the area until the grid power demand is within the grid power supply.


To run thhe loadshedding webapplication:
• Run the server.cpp file
• Run the index.html file with a live server and change to a browser
